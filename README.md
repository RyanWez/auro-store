# 🛍️ Aura Store — Myanmar Telegram Reseller Platform & Admin Dashboard

**Aura Store** is a fully automated, serverless Telegram Reseller Bot and Next.js Web Admin Dashboard designed for the Myanmar market. It allows customers in Myanmar to purchase international digital accounts, subscriptions, and AI API keys in **Myanmar Kyat (MMK)** via **KPay and WavePay**, automatically fulfilling orders through upstream Partner REST APIs.

---

## ⚡ Highlights
- **100% Free Hosting:** Zero monthly server costs using Vercel Serverless + Supabase PostgreSQL Free Tier.
- **Instant Digital Delivery:** Automated upstream fulfillment delivers activation codes & account credentials in seconds.
- **Myanmar Localized UX:** Inline buttons, quantity steppers, MMK pricing, and KPay/WavePay slip approval desk.
- **Comprehensive Admin Panel:** Realtime upstream USD balance tracker, dynamic exchange rate adjustments, profit margin controls, and customer wallet management.
